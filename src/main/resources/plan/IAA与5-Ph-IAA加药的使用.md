# 使用
## 配置含有IAA的板子
 按照下列表格配置

**400mL溶液，IAA终浓度1mM**

|    加入物质     |   加入量   |
|:-----------:|:-------:|
|     琼脂糖     |   8g    |
|     蛋白胨     |  0.8g   |
|    NaCl     |  1.2g   |
| 5mM 胆固醇酒精溶液 |  400μl  |
|      水      | 直到400mL |

高压灭菌，冷却之后加入下表

|        加入物质         |   加入量   |
|:-------------------:|:-------:|
|    400mM IAA酒精溶液    |   1mL   |
|        磷酸缓冲液        |  10mL   |
| 1M MgSO<sub>4</sub> |  400μl  |
| 1M CaCl<sub>2</sub> |  400μl  |
|          水          | 直到400mL |

之后放置应该避光，涂菌，然后避光4℃保存
 
<i><font color="#888888">400mL液体我大概一次能配出50个，差不多一次性用的</font></i>
